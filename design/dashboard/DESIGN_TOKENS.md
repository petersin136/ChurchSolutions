# 대시보드 v2 디자인 토큰

시안 PNG는 **1440×1252**(01–04) / **1440×1326**(05–14). `DASH_GLOBAL.baseWidth = 1440`과 같으므로 **1 PNG px = 1 CSS px**. 스케일 환산 없음.

추출: Python Pillow + numpy. 막대·dot는 안티앨리어싱을 피해 **도형 중심**을 샘플링했다. 글리프 높이는 잉크(어두운 픽셀) bounding box다.

앱 코드는 이 단계에서 수정하지 않았다.

## 6. 01·04 vs 현재 코드 차이 (우선순위)

라이브 localhost는 로그인 세션이 없어 캡처하지 못했다. 아래는 **시안 PNG ↔ 현재 소스** 대조다.

### 반드시 맞출 색

1. 출석률 막대 `#33473b` → `#5b7be6` / 빈칸 `#ebebef`
2. 성도 dot `#c3b1fa` → `#3a9a8c` / 빈칸 `#e3e4e9`
3. 그래프 강조 `#ff7044` → `#5b7be6`, 일반 `#c6c9d1`, 트랙 `#ebebef`
4. 부서 1위 `#e0e447` → `#d468c8`
5. W/M/Y 활성 `#d8dce3` → **검정 `#0b0c0e`**
6. 심방 카드 회색 → 흰색
7. 로그아웃 hover 빨강 → 설정과 같은 회색 (대시보드 한정)

### 카피·구조

1. `현황 보고` → **최근 사역**. 빈 문구도 시안: `아직 사역 기록이 없습니다.`
2. 중간 카드 서브: `정착 진행 3명`, `위험 1명 · 휴면 2명`, `예정 7건`, `응답 2건`
3. 큰 숫자 접두: `등록` / `합계` / `완료` / `요청`
4. 기도 큰 숫자 단위가 시안에선 **명** (코드는 건)
5. 출석률 서브: `활동 성도 93명 중 70명 출석`
6. 성도 서브: `활동 93 · 비활동 8` (슬래시 아님)
7. 부서 빈 상태: `조직/자원관리에서 부서를 추가해 주세요.` + ↗ (코드는 + 버튼)
8. 주간 뷰에서 연도 셀렉트 숨김. 월/년에만 표시
9. 그래프에 풀높이 트랙 + 툴팁

### 레이아웃

1. `contentPadLeft` 40 → 24, `contentPadTop` 32 → 24. **공유 토큰이라 대시보드만 오버라이드**
2. 히어로 숫자 62 → ≈50
3. 부서 막대 높이 48 → 34

## 7. 데이터 연결 (가짜 DB 금지)

연결 가능한 기존 값:

- 출석률, 전체 성도, 활동/비활동, 새가족 수, 위험+휴면 수, 출석 주/월/년 집계, 부서별 인원, 피드 건수

연결이 애매한 것 (PROGRESS 확인 필요):

- 심방 **예정** vs **완료** — 코드는 최근 visit 건수만 씀
- 기도 **요청 N명** vs **응답 N건** — 코드는 기도문 있는 성도 수(건)
- 툴팁 `240/300명`, `활동 평균 72/87명` — 분자/분모가 이미 주간 `present/total`에 있으면 그걸로 표시. 없으면 UI만

## 8. 임의로 정하지 않은 값

적혀 있지 않아 추정만 하고 구현 때 보수적으로 둔다.

- 카드 그림자 알파 (PNG에 없음)
- 드롭다운 호버 행 정확한 HEX
- M 버튼 호버 정확한 HEX
- 툴팁 radius·패딩 (블랙 알약. 시각적으로 radius 6–8, 패딩 8–12)
- 중간 카드 화살표 정확한 px (코드 36. 시안과 크게 안 다름)
- 폰트 패밀리 파일명 (시안에 안 적힘. 기존 Inter/Pretendard 유지)
